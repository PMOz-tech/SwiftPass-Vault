# SwiftPass Vault local reproduction

Open `index.html` to view the page. The CSS and JavaScript are bundled inside that HTML file; the exact public logo, folder artwork, icons, and social marks used by the page are stored locally in `assets/`.

The reproduction does not collect, store, or transmit user information. Navigation links point to the corresponding public SwiftPass pages. Use this reproduction only if you have permission and in accordance with the target website's terms and applicable rights.
